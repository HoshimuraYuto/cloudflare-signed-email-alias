# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/HoshimuraYuto/cloudflare-signed-email-alias/security/advisories/new).

Include the steps to reproduce it and the version or commit you used. Leave out your
domains, inboxes, tokens and keys.

You can expect a first reply within a week. If the report is accepted, a fix is released
and the advisory is published once users can update; if it is declined, the reply says why.
